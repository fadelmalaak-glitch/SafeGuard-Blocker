# تطبيق SafeGuard Blocker (حظر المواقع الإباحية ومنع الحذف نهائياً)

## كيف يعمل التطبيق؟ (3 طبقات حماية مدمجة)
1. **فلتر شبكة شامل (VpnService DNS Filter):** يمرر جميع طلبات الـ DNS في الموبايل عبر خوادم Cloudflare Family (`1.1.1.3`) و CleanBrowsing (`185.228.168.10`) لحجب المواقع الإباحية في جميع المتصفحات والتطبيقات بدون إبطاء سرعة الإنترنت.
2. **حارس المتصفحات والإعدادات (AccessibilityService):** يقرأ شريط العنوان ومحتوى المتصفحات (Chrome, Firefox, Brave, Samsung Internet, Opera وغيرها) في الوقت الفعلي؛ وبمجرد رصد أي كلمة أو نطاق إباحي يغلق الصفحة فوراً ويخرج للشاشة الرئيسية. كما يمنع الدخول لصفحة إعدادات التطبيق أو إيقافه الإجباري.
3. **منع الحذف الجذري (Device Owner / Device Admin):** يمنع إلغاء تثبيت التطبيق أو إيقاف الـ VPN أو تعديل الـ Private DNS من إعدادات أندرويد.

---

## خطوة 1: تحويل المشروع إلى ملف `APK` جاهز للتثبيت (بدون الحاجة لـ Android Studio)
لأن بناء ملف APK يتطلب مترجم Android SDK الرسمي، تم تجهيز ملف بناء سحابي تلقائي (`.github/workflows/build-apk.yml`):
1. قم بإنشاء حساب مجاني على موقع GitHub وارفع ملفات هذا المشروع في مستودع جديد (Repository).
2. اضغط على تبويب **Actions** أعلى المستودع، وستجد عملية **Build SafeGuard APK** تعمل تلقائياً.
3. بعد دقيقتين، اضغط على العملية المكتملة وحمّل ملف **`SafeGuard-Blocker-APK`** على موبايلك وثبّته.
*(أو يمكنك فتح مجلد المشروع مباشرة عبر برنامج Android Studio على الكمبيوتر والضغط على `Build -> Build APK`).*

---

## خطوة 2: تفعيل القفل الأبدي (منع الحذف حتى على صاحب الهاتف)
في نظام أندرويد، أي تطبيق عادي يمكن للمستخدم إيقاف صلاحياته من الإعدادات إلا إذا تم ترقيته إلى **مالك الجهاز (Device Owner)** عبر أمر `ADB` لمرة واحدة فقط:

1. ثبّت التطبيق على موبايلك وافتحه لتفعيل الخطوات الثلاث.
2. وصّل الموبايل بالكمبيوتر (أو استخدم تطبيق LADB على الموبايل) مع تفعيل **تصحيح أخطاء USB (USB Debugging)** من خيارات المطور.
3. نفّذ الأمر التالي:
   ```bash
   adb shell dpm set-device-owner com.safeguard.blocker/.GuardDeviceAdminReceiver
   ```
4. ارجع للتطبيق واضغط على زر التفعيل مرة واحدة، ثم أغلق **خيارات المطور (Developer Options)**.

بمجرد تنفيذ هذا الأمر:
- يختفي زر **Uninstall (إلغاء التثبيت)** وزر **Force Stop (إيقاف إجباري)** نهائياً من نظام أندرويد (`setUninstallBlocked`).
- يتم قفل الـ VPN بوضع **Always-On VPN Lockdown** بحيث لا يمكن إيقافه أو فتح أي متصفح بدونه (`DISALLOW_CONFIG_VPN`).
- يتم قفل تعديل إعدادات الـ **Private DNS** (`DISALLOW_CONFIG_PRIVATE_DNS`) وقفل الوضع الآمن (`DISALLOW_SAFE_BOOT`).
