# SafeGuard — فلتر المحتوى الإباحي (أندرويد)

تطبيق **ضبط نفس شخصي** يحجب المحتوى الإباحي على جهازك أنت. مبني بأندرويد SDK خالص
(بدون مكتبات خارجية) عشان يتبني ويتثبت بثبات، حتى على أندرويد 15 (مثل Oppo Reno 15).

> ملاحظة صريحة ومهمة: ده أداة **ظاهرة** لمساعدتك على ضبط نفسك — مش برنامج مخفي ولا
> «مستحيل يتشال». البرنامج المخفي اللي مايتحذفش هو تعريف برامج التجسس الضارة، وما
> نعملوش. بدل كده التطبيق يوفّر **حاجز قوي** (كلمة سر + جدولة + منع حذف عبر Device Admin)
> يصعّب إيقافه في لحظة اندفاع، وده المبدأ اللي بتشتغل بيه برامج المساءلة الحقيقية.

---

## إزاي تنزّل ملف الـ APK

كل مرة يتعدّل الكود، GitHub Actions يبني الملف تلقائياً. فيه طريقتين للتحميل:

1. **من صفحة Releases** (الأسهل من الموبايل): افتح تبويب **Releases** في الريبو،
   هتلاقي أحدث إصدار واسمه `SafeGuard APK (build رقم)`، نزّل منه ملف **`SafeGuard.apk`**.
2. **من Actions**: افتح تبويب **Actions** → آخر تشغيل ناجح (علامة ✓) → قسم **Artifacts**
   → نزّل **`SafeGuard-APK`** (ملف مضغوط فيه الـ APK).

## إزاي تثبّته

1. على الموبايل، افتح ملف `SafeGuard.apk`.
2. لو ظهر تحذير «تثبيت من مصدر غير معروف»، فعّل السماح لمتصفحك/مدير الملفات بالتثبيت.
3. كمّل التثبيت عادي.

## إزاي تفعّله (من داخل التطبيق)

افتح التطبيق وأول مرة اختَر **كلمة سر (PIN)** — هتحتاجها عشان توقف الحماية لاحقاً.
بعدها فعّل الطبقات الثلاث بالترتيب:

1. **فلتر الشبكة (VPN):** يشتغل على **كل المتصفحات والتطبيقات** عبر فلترة DNS
   (CleanBrowsing Adult + Cloudflare for Families). وافق على طلب الـ VPN لما يظهر.
2. **حارس المتصفحات (Accessibility):** خط دفاع إضافي يمسك المحتوى اللي ممكن يعدي من
   فلتر DNS (زي المتصفحات اللي بتستخدم DNS-over-HTTPS). فعّل خدمة *SafeGuard Content Guard*.
3. **منع الحذف (Device Admin):** يمنع حذف التطبيق قبل ما تعطّله كـ Device Admin أولاً،
   فبيضيف حاجز واضح قبل الحذف.

## التشغيل التلقائي والجدولة

- افتراضياً الحماية تشتغل تلقائياً من **4:00 العصر حتى 5:00 الفجر** كل يوم.
- تقدر تعدّل الساعات من زر **«تعديل مواعيد الجدول»**.
- أو تخليها **طوال اليوم** بزر الوضع (ده أقوى).
- بتفضل شغّالة بعد إعادة تشغيل الموبايل.

## لإيقاف الحماية أو حذف التطبيق

- من داخل التطبيق: زر **«إيقاف الحماية»** ويطلب كلمة السر.
- لحذف التطبيق: الأول عطّله من **الإعدادات → الأمان → تطبيقات مسؤول الجهاز (Device admin apps)**،
  بعدها احذفه عادي.

## (اختياري ومتقدّم) قفل أقوى ضد الحذف عبر ADB

لو عايز مقاومة أقوى بكتير للحذف، تقدر تخلي التطبيق **Device Owner** من جهاز كمبيوتر
(مرة واحدة، والجهاز مفيهوش حسابات مضافة):

```
adb shell dpm set-device-owner com.safeguard.blocker/.GuardDeviceAdminReceiver
```

ساعتها التطبيق هيمنع حذف نفسه على مستوى النظام. **ده قابل للتراجع** منك إنت من جهازك
عبر:

```
adb shell dpm remove-active-admin com.safeguard.blocker/.GuardDeviceAdminReceiver
```

أو عبر Factory Reset. يعني إنت دايماً تقدر ترجع فيه — عشان كده هو ضبط نفس قوي، مش فخ.

## ملاحظات تقنية

- `minSdk 24`، `targetSdk 33` (عمداً، لتفادي تشدّد Android 14 في أنواع الخدمات الأمامية
  وضمان تثبيت/تشغيل ثابت عند التحميل الجانبي).
- الـ APK موقّع بمفتاح الـ debug عشان يتثبّت مباشرة بدون إعداد مفاتيح.
- لا توجد أي مكتبات خارجية — أندرويد SDK خالص.
- الفلترة الأساسية بتحصل عبر خوادم DNS متخصّصة في حجب المحتوى الإباحي، مع قائمة محلية
  إضافية للحجب الفوري.

## حدود يجب معرفتها بصراحة

- أي فلتر محتوى مش 100%؛ ممكن موقع جديد يعدي لفترة لحد ما يتحدّث الفلتر.
- بعض المتصفحات بإعدادات DoH خاصة ممكن تتجاوز فلتر DNS — وهنا بييجي دور حارس
  المتصفحات (الطبقة 2).
- VPN واحد بس بيشتغل في نفس الوقت على أندرويد؛ تفعيل VPN تاني هيوقف الفلتر.
